# back_walk 裁剪修复（2026-10-10）

本轮仅处理back_walk。以实际最新shared20_clean5训练数据为底，其他19类逐条记录完全不变；未启动训练。

原1118train/135val中，有763条原速度标签非正；1078条原真实帧具有超过2%的前向路径成分。这两个统计有交集。候选来源中的纯前走、前后混合、转身后向前走、短暂后退等不能仅凭原描述或世界坐标位移当作倒走。

修复依据身体朝向投影的逐帧前后速度，在原标注时间区间内裁取连续倒走，去掉补帧，重算实际任务速度。无合格区间的条目剔除；再检查侧向比例、转角、双脚踏步及躯干直立程度。训练预览发现明显弯腰后退后，V2加入0.70rad躯干倾斜上限。最终156train/25val，来自137/22个源录制；159个原记录产生181个窗口，其余1094个原记录没有满足规则的窗口，不应将它们一概称为纯前走。

新片段2–6秒，最大前向路径比例0.1985%（仅微小波动，未保留持续前走段）。所有181缓存与原20fps源片段精确一致，速度重算误差0；全20类源family划分隔离、文本编码/PCA/掩码核验通过，5项回归测试通过。原描述、原速度、原裁剪、原cache、新边界与新标签均已保存。为避免原整段描述继续提示前走，新片段文本统一为walk backwards，原描述另存审计；这不是声称取得了新的BABEL官方时间标签。

本次只修复方向与裁剪，未宣称所有手臂动作或次要活动均已清除。10个不同TRAIN来源的视频已检查起中末抽帧，呈现后退踏步；仍等待用户复核。范围覆盖见coverage.json，保持原0.35–0.9m/s任务范围，不为凑范围而重定时。

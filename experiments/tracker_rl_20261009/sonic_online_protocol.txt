Clean official SONIC + online PPO residual (2026-10-10; queued, not yet a result)

The user's priority remains training from scratch. Both existing scratch runs
continue. This additional experiment tests whether a clean general controller
provides a useful initialization; no historical specialist heads or trajectories
are loaded. Its success would motivate transferring mechanisms to scratch runs,
not claiming that public pretraining has been reproduced from scratch.

Method
------
Direct official ONNX import, fixed SHA256 allowlist. The frozen mode0 encoder and
decoder contain 14,415,453 parameters. None require gradients or enter the PPO
optimizer. A newly initialized shared MLP [512,256,128], with zero last layer,
learns an additive motor-action residual using ordinary online PPO. Initial action
noise std=0.1 in normalized action coordinates. Actor input is the existing 361D
current/future observation, followed by 29 nominal actions and 64 SONIC tokens.
Critic uses its existing privileged observation plus the same nominal/token terms.
The base action is a controller component, not a supervised regression target.
No behavior cloning loss, distillation loss, expert-action cache or task routing.
The original nine BeyondMimic-style rewards and physical terminations are unchanged.
Training_drift_threshold is null for this fine-tuning experiment.

State semantics
---------------
PPO stores residual samples/log probabilities. Only the environment boundary adds
the nominal action and applies configured clipping. History records the actual
executed combined motor action, transformed into SONIC action coordinates.
Each reset environment gets ten copies of its new proprioception with previous
action zero. Non-reset histories shift by exactly one frame. Repeated observation
reads do not advance history. Future reference indices stop at the current clip.

Reproduce (paths may be overridden with Hydra)
---------------------------------------------
Install requirements-tracker-rl.txt and requirements-tracker-sonic.txt in the RL
environment. Do not combine with the separate GMR retarget environment.

python scripts/train_tracker_rl.py --config-name sonic_residual \
  experiment=sonic_online_v1 run_date=20261010 num_envs=2000 iterations=3000 seed=51001

Evaluate/export with scripts/evaluate_tracker_rl.py or scripts/export_tracker_rl.py:
  checkpoint=<training/model_N.pt> output=<new directory> preview_offsets=[5,10,20] \
  +sonic_directory=<official release ONNX directory> \
  +sonic_contract=configs/release/inference_contract.json

Deploy with scripts/follow_tracker_rl.py:
  policy=<export/policy.pt> policy_kind=sonic_rl contract=<export/contract.json> \
  legacy_contract=<export/sonic_contract.json> scene=<export/scene.mjb> \
  reference=<prepared50Hz motion.npz> output=<new directory>

The export stores five preview offsets for compatibility with the original2350D
runtime ABI. The new residual uses only the first three, matching its training.
The two unused previews are not silently added to the learned input.

Follow and continuation validation
----------------------------------
The real walk42001 follow command runs all298 frames. Its recorded states/actions
equal the batch evaluator exactly (maximum differences0). Running walk, then jump,
then walk again through the same policy instance also reproduces states/actions
exactly: reset clears causal controller history and does not leak across commands.
This validates runtime consistency, not extra evidence of task generalization.

SONIC continuation now restores actor, critic, normalization and optimizer exactly,
including the optimizer's adaptive LR scalar. A 40-to-80 environment continuation
passed for two updates. It starts a new seeded simulator segment; it does not claim
bitwise reproduction of an interrupted training process. Official ONNX hashes and
the physical action/observation contract are checked before any continuation.
The contract is copied and SHA256-recorded in each SONIC training report. A changed
action scale was rejected before creating a new run. Queued formal SONIC source was
updated with these provenance-only additions BEFORE its training process started;
neither running scratch experiment's source was changed.

Official-only20-class videos, seed42001, have been rendered and visually checked
for walk and a terminated jump case. Terminated means the evaluator's physical
tracking rule fired; it does not necessarily mean the robot fell. The red tail
label identifies held last recorded frames. These videos are a pretrained baseline,
not the eventual online-RL deliverable or evidence of improvement from this project.

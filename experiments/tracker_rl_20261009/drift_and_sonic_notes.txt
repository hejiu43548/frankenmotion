2026-10-10 supplementary experiment protocol (ongoing, not final conclusions)

User preference: prioritize training from scratch. Fine-tuning a clean shared
policy or official SONIC is permitted, but successful techniques must also be
tested from scratch. Historical specialist teacher actions, residual heads and
distillation remain excluded. Current scratch runs are not cancelled.

Hypothesis and evidence
-----------------------
The selected scratch preview policy at update 4000 can stay upright far away
from the reference. On validation back_walk, mean root error is 0.864/0.900 m;
58.7/60.1% of frames exceed 0.5 m. In these frames total weighted reward remains
3.731/3.717 per step (root position component approximately 0.001). This is an
observational grouping of pre-step error and following-step reward, not a causal
proof. Relative body tracking and stability can coexist with global path drift.

PHC discusses global joint deviation termination and relaxed foot termination:
https://arxiv.org/html/2305.06456v3
SONIC documents adaptive termination thresholds and motion sampling:
https://nvlabs.github.io/GR00T-WholeBodyControl/user_guide/configuration.html
We test a simpler fixed threshold as a diagnostic, not a reproduction of PHC.

Clean official SONIC import and baseline
--------------------------------------
Local official repository commit b042411fae38ee4d1af9aac82a37a1f8d14d6dd0.
HF cached snapshot 6733128a3d8a523b1418b06bca3cdf61c8b0987f.
Official source: https://huggingface.co/nvidia/GEAR-SONIC
Mode 0 = G1 robot motion input; mode 2 = SMPL pose input (plus wrist references).
Release input layout differs from v1.1; never swap checkpoints without the ABI.
Official configuration: gear_sonic_deploy/policy/release/observation_config.yaml.

Source ONNX hashes are pinned in shared_motion/rl/sonic.py. Matching local HF
snapshot symlinks point to content-addressed blobs. Live public-network verification
failed due connectivity; provenance claim is based on this cache and official docs.
The import path reads ONNX initializers directly; no historical tracker, head,
normalizer, teacher trajectory or action dataset is read. Decoder/encoder are frozen.
Optional import dependencies: onnx==1.23.1, onnxruntime==1.23.2.

128 random inputs per module: mode0/mode2 encoder maximum CPU and CUDA difference
from ONNX Runtime is zero. Decoder errors 2.861e-6 CPU, 3.338e-6 CUDA. This checks
batched graph conversion, not a claim that robot dynamics or task quality matches
the official deployment. The first extraction attempt omitted timewise feature
interleaving and failed parity; it was corrected before any policy evaluation.

The resulting standalone mode0 policy keeps 10 causal proprioception frames and
uses the same native 2350D ABI. It ignores the old residual-head input features.
Unlearned joint permutations and actuator scales come from the native ABI contract.
No zeroed teacher-trained head is loaded or retained.

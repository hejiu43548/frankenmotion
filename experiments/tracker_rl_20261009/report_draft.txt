统一 G1 Tracker 在线强化学习实验：阶段性技术记录
日期：2026-10-10（Asia/Shanghai）
状态：实验进行中。此文件不是最终结论或可替换现有 tracker 的发布声明。

一、研究问题与边界
本实验研究能否在官方 FrankenMotion 生成的参考动作上，通过直接与 MuJoCo
交互的 PPO，训练一个覆盖 20 类动作的统一 tracker。它模仿的是参考运动学
轨迹，不是历史优化策略输出的动作。训练代码不加载旧 shared20、单动作策略、
专家动作标签或教师 rollout。旧 shared20 仅用于独立评测。
按照用户澄清，从零训练是优先路线，但允许从干净的通用预训练控制器开始在线
学习。当前同时探索随机初始化和官方 SONIC 加新建 RL 残差两条路线。后一条
必须单独标为预训练初始化，不把它已有的控制能力算成本项目从零训练的成果。

二、相关工作如何影响设计
DeepMimic（https://xbpeng.github.io/projects/DeepMimic/index.html）说明参考运动
可以直接构成 RL 模仿目标，参考状态初始化能够降低探索难度。本实验使用这一
思路，并在训练中混合从头开始和随机参考帧开始；评测始终从头开始。
BeyondMimic（https://arxiv.org/abs/2508.08241；
https://github.com/HybridRobotics/whole_body_tracking）提供跟踪 MDP 的参考。
本实验使用 mjlab 的公开 G1 跟踪实现与固定奖励配置，不执行策略蒸馏阶段。
实现依托 https://github.com/mujocolab/mjlab 和
https://github.com/leggedrobotics/rsl_rl，固定实际安装版本与源码完整性记录。
RobotDancing（https://arxiv.org/abs/2509.20717）和 Residual RL
（https://arxiv.org/abs/1812.03201）支持把参考关节姿态与在线学习修正量结合
这一设计方向。本实验中的参考量来自运动学数据，不是教师控制器。
PHC（https://arxiv.org/html/2305.06456v3）的参考初始化与失败提前终止提供了
另一条方向。当前试验只借鉴全局偏离后提前结束训练片段的思想，没有复现其
完整系统，也没有引入其专家策略、蒸馏或额外判别器损失。
SONIC（https://arxiv.org/abs/2511.07820）提供公开的通用预训练基线。官方
release 的 mode0 接收机器人参考，mode2 接收人体姿态及手腕输入。两种编码器
均已直接从官方 ONNX 独立导入并核对数值；当前完整在线 RL 接入使用 mode0。
其十帧因果状态历史必须记入实际执行的残差叠加动作，不能记录未执行的提议。
不把本次单卡、160 条生成动作的实验称为 SONIC 规模的复现。官方接口依据：
https://nvlabs.github.io/GR00T-WholeBodyControl/user_guide/configuration.html
GMR（https://github.com/YanjieZe/GMR）用于统一重定向。服务器 GMR 是无 Git
元数据的解包快照，已保存含许可证的源码与资源归档，而非虚构一个上游提交号。

三、数据划分与可重复准备
20 个提示词每类生成 8 个随机种子，共 160 条 6 秒动作。训练种子 41001–41004
共 80 条，验证 42001–42002 共 40 条，测试 43001–43002 共 40 条。
这是生成种子隔离，不是动作类别隔离，也不是独立动捕数据库上的泛化实验。
所有动作使用相同重定向与插值方式，无根据策略表现挑选或手工修补的动作。
训练及验证 120 条运动学检查中，没有动作超过 10% 的帧出现足部低于地面
2cm 的情况。这不等于运动动力学可行，也不证明文本语义正确。

进一步在未修改的训练/验证参考上检查质心的离地运动：使用实际机器人质量和
碰撞几何，要求连续 11 帧内所有机器人碰撞体都离地超过 3cm，再估计质心的
竖直加速度。场景没有重力补偿、外部约束或运动捕捉驱动，接触 margin 为0。
已知弹道平移的标定误差约1.0e-12 m/s²，支持数值实现正确。
lean 与 squat 各6条参考都出现了持续离地但质心近乎不下降的窗口；每条中位
加速度与重力差的跨动作中位数分别约9.91和9.81 m/s²。jump 的6条参考对应
约2.98 m/s²。这里包括训练4种子及验证2种子，没有查看测试集。
这提示部分参考含几厘米的悬空或非弹道跳跃，并非完整的动力学可行性判定。
平滑、重定向和插值误差也会影响该诊断。事实上 squat 仍可在严格指标下成功，
因此不能把这些结果当作所有 RL 失败的解释，更不能据此删掉难例。数据未被
修正、过滤或重新生成；具体记录见 airborne_reference_diagnostic.json。

数据准备曾发现并修复两个数值问题：足部碰撞体是 capsule，不能按 sphere
处理其最低点；MuJoCo 的 mjOBJ_BODY 速度位于质心，参考跟踪需要 mjOBJ_XBODY
的刚体坐标原点速度。后一项通过有限差分验证。地面对齐只在每条参考开始时
执行一次，运行中不将身体投影回地面。

四、训练与评测协议
初始筛选比较三种从随机参数开始的策略：当前参考输入、未来参考输入，以及
参考关节位置加 RL 残差。未来偏移为 5/10/20 帧，即 0.1/0.2/0.4 秒。
每组初始预算为 400 并行环境、每次 24 步、3000 次更新，即 2880 万交互步。
公开上游默认更新长度是 30000 次；初始筛选不能代替充分训练的结论。
奖励固定为 6 个跟踪项及动作变化、关节极限、自碰撞 3 个正则项。没有增加
逐任务奖励。残差方案的动作历史和动作变化奖励仍针对实际电机目标。

在初始筛选之后，选定未来参考策略增加6000次更新、2000并行环境，即另外
2.88亿步。同时从随机参数启动同样未来参考输入的实验，额外设置训练阶段
全局锚点偏差>0.5m时结束片段，预算6000次、2000环境。它不改变九项奖励，
评测时也不启用这条新终止条件。这两组起始并行规模不同，不能视作严格受控
消融；当前证据只支持比较完整训练配置，不能单独归因于终止机制。

第三条已排队的路线是官方 SONIC 加新的共享 PPO 残差。官方网络直接从固定
哈希的 ONNX 加载，没有从旧 tracker 删除或复用专项残差头。其约1442万参数
全部冻结且不进入优化器；新残差 MLP 为512/256/128，输出层零初始化，动作
噪声初始标准差0.1。PPO通过仿真回报更新残差，没有任何动作标签回归或蒸馏
损失。正式预算2000环境、3000更新，即1.44亿在线交互步；它不复现公开
预训练所用的海量数据和算力。待当前长程从零试验结束后启动，保持两项主要
训练并行；已完成的短训练仅用于验证工程链路，不能据此声称 RL 提升。

评测每条动作从第 0 帧开始，确定性策略，无中途重置、扶持力或失败后的补救。
完整率指在给定物理终止条件下执行完参考。严格成功还要求平均全局锚点误差
<0.15m、身体误差<0.20m、关节 RMS<0.40rad。这些阈值在正式训练策略评测前确定。
字段 root_m 实际衡量 torso_link 的全局锚点位置误差，不能误读为骨盆平移误差；
身体误差是14个受跟踪刚体原点的世界坐标距离均值。完整率记录统一物理跟踪
终止条件下的完成情况；触发终止不一定意味着机器人倒地。
失败后的未观测尾部使用固定 0.5m 根/身体误差及 1rad 关节误差记账，另外同时
提供已观测段误差、失败帧和执行时长。不能只报告存活样本误差。
原生 MuJoCo 与 Warp 分开汇报，旧/新策略主要比较使用同一原生评测器。
比较工具检查场景哈希、每条参考文件哈希、动作身份、时长、种子和扰动条件。
任务聚类 bootstrap 区间描述当前任务组合的变异，不包含训练随机种子不确定性，
也不构成对新动作类别的泛化保证。验证集上的区间仍然是探索性结果。

五、目前已完成的主要结果（均为验证集，尚非最终测试结果）
同一原生 MuJoCo 评测中，现有 shared20 完整率 80%，严格成功率 75%，带失败
尾部记账的锚点误差 0.13694m；当前参考 PPO 最后检查点完整率 77.5%，严格成功
40%，锚点误差 0.36508m。严格成功率差为 -35 个百分点，任务聚类区间约
[-55,-17.5] 个百分点。第一轮明确没有超过现有策略。
未来参考 PPO 最后检查点原生评测完整率 72.5%，严格成功率 42.5%，锚点误差
0.33737m。GPU 评测完整率 75%，严格成功率 42.5%；不同后端数值不混合汇总。
纯参考姿态 PD 对照的完整率为 0%，说明参考关节角本身不足以完成这些任务。
现有 shared20 加初始速度扰动的另一个验证试验完整率 82.5%、严格成功率77.5%。
这个小样本结果不意味着扰动有益；需在相同扰动种子上做成对候选比较。

观察到的主要失败是移动类动作的全局路径漂移：站立和平衡有所改善，但没有
可靠跟随参考位移。动作变化更小不能作为质量提升依据。
参考姿态加 RL 残差的3000次筛选已完成，原生完整率67.5%、严格成功42.5%，
带失败尾部的锚点误差0.33033m，关节误差0.29926rad，尚无整体优势。

独立导入的官方 SONIC mode0（没有本次 RL）的原生完整率95%、严格成功75%，
锚点误差0.11955m，关节误差0.13582rad。相对旧 shared20，严格成功率持平，
完整率提高15个百分点；这属于公开预训练基线的差别，不是本轮 RL 的成果。

从零加偏离终止的第1000次更新，在原生评测中完整率80%、严格成功50%，
锚点误差0.14571m、关节误差0.29677rad。相对 shared20 的严格成功差-25个
百分点，任务聚类区间[-45,-7.5]个百分点；仍未超过基线。该检查点的 GPU
完整率75%、严格成功52.5%，因此不同后端分开保留，不能挑更好的数字混算。
未加偏离终止的延长训练在第6000次检查点 GPU 严格成功仍为50%，锚点误差
降至0.26861m。训练仍在进行，上述数字是明确检查点的阶段记录，不是最终
检查点选择、独立测试结果或对最终模型质量的承诺。

从零偏离终止实验第2000次更新：原生完整率85%、严格成功77.5%，锚点误差
0.12152m、关节误差0.27208rad。GPU 完整率85%、严格成功72.5%。原生相对
旧基线严格成功增加2.5个百分点，任务聚类95%区间[-12.5,17.5]个百分点；
锚点误差差值-0.01541m，区间[-0.04885,0.01279]m，均不能证明显著改善。
关节误差反而更高，平均完成时长比例也略低（89.7% 对90.7%），表明少数
失败可能更早发生。逐类看，前倾和鞠躬改善，倒走退步；跳跃、踢腿、挥击
仍然失败。首次出现严格成功率数值略超旧基线，不能据此结束实验或宣称
明显提升。已导出独立策略并渲染全部20类验证视频；未开启测试集。

第2000次更新还做了成对初始速度扰动：基座线速度三个分量各加入[-0.3,0.3]
m/s，角速度三个分量各加入[-0.3,0.3]rad/s的均匀扰动。随机种子61001加参考
生成种子，两策略共享相同扰动；相同生成种子的不同类别也共享这个六维向量。
这只是起始条件敏感性诊断，并非中途推搡恢复或大量随机扰动鲁棒性证明。
旧基线重新通过带参考哈希的评测入口运行，结果与早期记录相同。扰动后两者
完整率均82.5%，从零严格成功75%对旧基线77.5%，差值区间[-15,12.5]个百分点。
从零关节误差0.27480rad，旧基线0.20658rad，差值区间[0.01026,0.12827]rad。
当前不能声称稳健性更强。该检查点及扰动结果均为验证集探索，不参与测试集调参。

未加偏离终止的延长训练第8000次检查点，GPU完整率升至95%，严格成功率
57.5%，锚点误差0.18832m、关节误差0.19176rad。与该分支第7000次的87.5%、
52.5%、0.23716m相比继续改善，但持续执行和准确跟踪仍明显不同。此处只在
同一GPU后端内描述进展，不能拿95%直接对照原生基线80%来宣称提升。

动态动作终止诊断：在同一原生评测器中重放旧shared20、官方SONIC0、从零
1000/2000共四种策略的jump/kick/strike两条验证参考，共24次。原评测的全部
逐片段指标完全复现，随后读取真正的末次物理步状态，而非视频中保留的前一帧。
四种策略的jump均在约135—139帧因踝部竖直误差超过0.25m终止：参考踝高约
0.31—0.38m，实际约0.05—0.12m。这表示没有跟上离地抬升，不等于已经摔倒。
从零2000的kick均在84帧终止，strike在59—60帧终止，均为右踝偏低超过阈值；
例如strike42001参考右踝0.875m、实际0.606m。旧shared20和官方SONIC的strike
则能完整执行，说明这些从零失败不能全部归咎于参考物理不一致。继续训练时
需要观察动作幅度和时序是否恢复，不能通过放宽评测阈值掩盖失败。
诊断文件terminal_end_effector_diagnostic.json保留逐策略/参考的四肢末端高度。
它没有修改终止条件、奖励、参考或策略，也没有生成任何教师训练数据。

从零偏离终止第3000次更新：GPU完整率87.5%、严格成功77.5%，原生却仅
82.5%和72.5%；原生锚点误差0.12393m、关节误差0.26190rad。相较2000次，
原生慢跑和前倾出现退步，挥击一条可完整执行但位置误差仍未达严格标准。
该反转说明GPU曲线不是实际follow质量的可靠排序替代。测试集仍未使用，
现明确最终按原生40条验证评测选择每个长期实验的全部既定检查点，排序规则
为严格成功、完整率、较低惩罚锚点误差；记录于final_selection_protocol.txt。
这是依据验证证据完善的协议，不伪称从实验开始就已预注册该后端选择。

六、工程复现证据
显式 reset 后刷新参考坐标，防止上游相对目标残留造成第一帧假终止；该问题
之前的探索运行已判无效，未纳入正式结果。每条参考末尾显式终止，防止拼接
数据越界到下一条动作并错误 bootstrap。真实环境集成测试涵盖这些边界。
导出 TorchScript 的策略动作与训练策略核对，原生初始观测与 GPU 观测最大
差约 2.12e-7。单条 follow 与批量评测在一条真实验证动作上的状态/动作差均为0。
新目录中的数据准备和场景导出与原实验文件 SHA-256 完全一致。
续训核对自身检查点、数据、源代码语义、依赖版本和优化器恢复，明确重建仿真
状态，不承诺逐位恢复一次未中断的 GPU 运行。最后更新编号和学习率恢复均显式处理。

官方 SONIC 两种编码器在128个随机输入上的 CPU/GPU 输出与原 ONNX 一致；
解码器最大差约3.34e-6。五类真实原生轨迹共1329帧的独立 ONNX 影子核对，
最终电机动作差最大3.49e-6。训练包装器另在40个真实环境的0/5/15/30步核对
原生输入，最大差低于1e-6，并验证非零残差的实际动作历史、部分重置以及
其他环境历史不受重置影响。导出模型在原仓库 Tracker 接口中动作差4.17e-7。
完整298帧的 follow 行走与批量评测逐帧完全一致；同一实例执行行走、跳跃、
再行走仍完全复现第一次行走，说明状态历史能正确清除。

SONIC续训也核对官方权重哈希及物理接口哈希，40到80环境的续训通过；修改
动作缩放会在创建新训练记录前被拒绝。原生部署的单文件 TorchScript 包含
基座和新残差，不依赖 ONNX Runtime，也不需要任何历史教师权重。

七、交给更高质量前期工作的迁移建议
先固定可回放的参考数据接口：50Hz、米/弧度、wxyz单位四元数、明确的关节及
刚体顺序、刚体原点速度；保留原始运动和重定向结果，分别记录哈希。仅检查
穿地不够，还应检查持续悬空、接触时序及离地质心运动。当前诊断没有自动
修正参考，迁移者应在其重定向流程中解决明确的物理矛盾并另行固定数据版本。

训练前先跑共享的输入/边界/导出测试，再跑纯参考PD、干净通用控制器和随机
初始化基线。明确公开预训练是否被使用，不把基座能力归于小规模在线训练。
